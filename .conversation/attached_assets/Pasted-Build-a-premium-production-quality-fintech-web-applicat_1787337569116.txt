Build a premium, production-quality fintech web application frontend called:

# FINORA

### Tagline:

**Understand. Simulate. Decide.**

Finora is an AI-powered personal financial decision platform designed around the problem of financial literacy vs financial confidence.

The application should help users understand their income, expenses, savings, investments, financial goals, risk profile, and hypothetical financial decisions.

The core product philosophy is:

**Complex financial data → Clear understanding → Personalized insight → Actionable decision**

IMPORTANT:

This phase is FRONTEND ONLY.

Do NOT build the backend, database, authentication service, real AI integration, payment system, broker integration, or real financial API integrations yet.

Use realistic local mock/demo data and clean frontend architecture so the backend can be connected later without redesigning the UI.

---

# 1. DESIGN DIRECTION

The application must look like a serious modern fintech startup, NOT a college project.

Visual references should feel like a combination of:

* Premium fintech SaaS
* Modern banking dashboard
* AI productivity platform
* Minimal enterprise analytics product

Use a clean LIGHT theme.

Primary visual style:

* White / off-white backgrounds
* Dark navy/charcoal typography
* One sophisticated primary accent color
* Very subtle gradients
* Soft shadows
* Rounded cards
* Clean borders
* Excellent spacing
* Modern typography
* Minimal but meaningful animations

Do NOT use excessive purple gradients.

Do NOT make every card colorful.

Do NOT use giant illustrations everywhere.

Do NOT make it look like a generic AI chatbot.

The product should feel trustworthy, intelligent, premium, and calm.
